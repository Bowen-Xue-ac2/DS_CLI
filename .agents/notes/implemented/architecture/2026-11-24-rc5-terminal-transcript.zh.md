# Agent Note: 终端实时输出与已提交历史分开展示

Status: implemented

[English](2026-11-24-rc5-terminal-transcript.md) | 中文

## 问题

终端订阅的已提交 Session 事件要等回复生成后才到达，无法展示部分回复。Host 重试时，终端也需要移除失败尝试的输出。

## 决策

rc.5 终端在现有 Session 订阅上启用实时助手帧。连接时用 Host 解码器恢复已收到的流前缀，接着按尝试标识和序号处理增量。已提交的助手消息替换预览，放弃尝试、重试或切换 Session 会清除预览。详览使用同一份视图数据，关闭时保留草稿。

## 考虑过的替代方案

轮询历史或把已提交的消息重新播放为增量，都要等模型生成完成后才出现内容。订阅实时帧可以展示进度，并继续用持久日志作为历史的来源。

## 后果

每个可展示的块保留有长度上限的预览，历史回放使用 Host 已提交的消息。提供方未返回思考文本时，终端仍显示当前阶段。用量统计涵盖终端已接收的 Session 事件。
